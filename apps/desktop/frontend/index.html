Network & USB Connectivity

Manage Wi-Fi and USB Tethering network interfaces

Active Host Interfaces
Android USB Wired Tethering 50ms Latency
  1. Connect your Android phone to the PC using a USB cable.
  2. Open phone Settings ➔ Network & Internet.
  3. Tap Hotspot & Tethering.
  4. Toggle on USB Tethering.
  5. The desktop immediately detects the wired RNDIS network adapter.
iPhone USB Wired Tethering 50ms Latency
  1. Connect your iPhone to the PC using a Lightning or USB-C cable.
  2. Open iPhone Settings ➔ Personal Hotspot.
  3. Enable Allow Others to Join.
  4. When prompted by iOS, tap Trust This Computer.
  5. The desktop immediately routes high-speed wired stream data.
